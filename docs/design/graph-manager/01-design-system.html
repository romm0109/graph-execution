graph-manager / design system

Tokens & components

Warm neutrals with one blue accent. The palette stays quiet, so color on screen nearly always means status. Six tones cover every status word, and each tone has its own glyph shape so it still reads in grayscale and for color-blind users.

Status palette: one tone, three vocabularies

ToneRunsTasksTerminalsLightDark
live running running · validating · merging working live live
ok applied merged — ok ok
warn review requested — idle warn warn
bad failed failed exited ≠ 0 bad bad
mute done · aborted pending exited 0 mute mute
rev review phase human review — rev rev

Glyphs: live = pulsing dot · ok = filled dot · done / exited 0 = ring · pending = dashed ring · bad = diamond · aborted = bar · warn = half-filled dot. Amber is only for “waiting on you” (an idle agent, a requested human review), never for decoration.
